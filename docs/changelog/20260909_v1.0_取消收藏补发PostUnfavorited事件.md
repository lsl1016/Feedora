# 取消收藏补发 PostUnfavorited 事件

## 1. 背景与目标

### 问题描述

- 取消收藏帖子成功后不发布任何事件：点赞侧取消有 `PostUnliked`，收藏侧取消无对应事件，事件流中缺少取消收藏记录。

### 根因分析

- `event_type.go` 中不存在 `PostUnfavorited` 常量，事件类型集合缺少取消收藏一项。
- `SetFavorite` 的取消分支在 `RemovePostFavorite` 成功后仅回减 `posts.favorite_count`，没有事件发布语句。

### 影响范围

- 下游消费者无法通过事件感知收藏取消，热度榜单对取消收藏不回扣分数（消费侧行为属 rank 模块）。
- `interaction.events` 主题中取消收藏动作不可观测。

## 2. 代码改动

- 文件：`internal/service/interaction_service.go`
  - `SetFavorite` 取消收藏分支：在 `RemovePostFavorite` 返回成功（实际删除关系行）后补发 `event.PostUnfavorited` 事件到 `event.TopicInteraction`，`bizID` 为帖子 ID、`userID` 为操作人、`payload` 为 `nil`，与点赞/收藏事件的发布口径一致。
- 文件：`internal/event/event_type.go`
  - 新增常量 `PostUnfavorited = "PostUnfavorited"`；同批新增 `PostUnhidden`、`TopicCreated`、`TopicUpdated` 常量，与本模块改动直接相关的是 `PostUnfavorited`。

## 3. 影响范围

- 接口：`DELETE /posts/:postId/favorite` 在实际取消成功时新增一次事件发布，请求参数与响应结构不变；重复取消（关系行不存在）不发布事件，保持幂等。
- 模块：interaction（事件发布）；消费侧 rank worker 对 `PostUnfavorited` 回扣帖子热度 ZSet 分数（该行为描述属 rank 模块文档），notification、growth、search 消费者不处理该事件。
- 配置：不新增配置项；事件是否实际投递仍由全局 `kafka.enabled` 决定（Outbox 或 Noop）。

## 4. 测试验证

- 命令：`go build ./...`、`go vet ./...`、`go test ./...`
- 结果：`go build ./...` 通过（exit 0）；`go vet ./...` 通过（exit 0）；`go test ./...` 结果 `ok github.com/feedora/backend/internal/api`，其余包无测试文件。集成路径未在真实 MySQL/Redis/Kafka 环境回归，以编译与现有单测验证。

## 5. 风险与兼容性

- 事件仅在关系行实际删除时发布，重复取消不会产生重复事件。
- `kafka.enabled = false` 时经 `NoopProducer` 仅打印日志，无下游影响。
- 新增常量不改变既有事件类型的取值，历史事件消费不受影响。
- notification、growth 消费者不处理取消类事件，取消收藏不撤销已生成的通知、不回退积分。
