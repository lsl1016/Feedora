## 25.5 AI 回答

Mock 生成规则：

```text
根据用户问题返回固定模板回答。
如果问题包含“面试”，返回面试准备模板。
如果问题包含“React”，返回 React 学习路线。
如果问题包含“Go”，返回 Go 工程化路线。
否则返回通用学习建议。
```

示例：

```ts
export function mockGenerateAiAnswer(question: string): string {
  if (question.includes('面试')) {
    return '可以从基础知识、项目经验、系统设计、数据库、缓存和表达能力几个方向准备。';
  }

  if (question.includes('React')) {
    return 'React 学习可以分为 JSX、组件、Hooks、状态管理、路由、工程化和项目实战几个阶段。';
  }

  if (question.includes('Go')) {
    return 'Go 学习建议从语法、并发、Gin、Gorm、Redis、Docker 部署和微服务实践开始。';
  }

  return '建议先明确目标，再拆分学习路径，最后通过一个小项目进行验证和沉淀。';
}
```

## 25.6 模型配置

```text
保存配置 -> apiKey 脱敏 -> 更新 mockUserModelConfig
测试连接 -> 返回成功
```

脱敏规则：

```ts
export function maskApiKey(apiKey: string): string {
  if (!apiKey) return '';
  if (apiKey.length <= 8) return '****';
  return `${apiKey.slice(0, 3)}****${apiKey.slice(-4)}`;
}
```
