# 社区 MVP 前端 UI 页面实现说明书

## 1. 整体 UI 风格

### 1.1 产品风格

本项目是一个内容社区类 Web 应用，整体风格要求：

```text
简洁、清爽、现代化、偏内容阅读体验。
```

推荐视觉风格：

| 项目    | 说明                          |
| ----- | --------------------------- |
| 主色    | 蓝色或紫蓝色，用于按钮、导航高亮、链接         |
| 背景色   | 浅灰色背景，页面主体使用白色卡片            |
| 卡片风格  | 圆角、轻微阴影、留白充足                |
| 字体风格  | 使用系统默认字体，保证中文阅读体验           |
| 交互风格  | hover 有反馈，点击后状态明确           |
| 页面宽度  | 前台页面主体建议最大宽度 1200px         |
| 内容流宽度 | 帖子列表建议 720px 左右，右侧可放推荐区或榜单  |
| 后台页面  | 使用典型管理后台布局，左侧菜单 + 顶部栏 + 内容区 |

# 2. 前台整体布局

## 2.1 前台基础布局

所有前台页面共用一个基础布局。

```text
┌──────────────────────────────────────────────┐
│ 顶部导航栏                                    │
├──────────────────────────────────────────────┤
│ 页面主体内容区域                              │
│                                              │
│   左侧 / 中间主要内容                         │
│   右侧辅助内容，可选                           │
│                                              │
└──────────────────────────────────────────────┘
```

### 顶部导航栏结构

```text
Logo / 社区名称   首页   热门   关注   通知   我的头像
```

### 顶部导航栏组件说明

| 组件          | 类型     | 描述                  |
| ----------- | ------ | ------------------- |
| Logo / 社区名称 | 文本或图片  | 点击后跳转首页             |
| 首页          | 导航菜单   | 点击跳转首页帖子流           |
| 热门          | 导航菜单   | 点击跳转热门榜单页           |
| 关注          | 导航菜单   | 点击跳转关注流页面           |
| 通知          | 导航菜单   | 点击跳转通知页，有未读数量时展示红点  |
| 我的头像        | 头像下拉菜单 | 点击后展开用户菜单           |
| 发布按钮        | 主按钮    | 建议放在导航栏右侧，点击进入发布帖子页 |

### 我的头像下拉菜单

点击头像后展示下拉菜单：

```text
我的主页
我的帖子
我的收藏
退出登录
```

交互效果：

| 操作          | 效果                    |
| ----------- | --------------------- |
| 点击我的主页      | 跳转我的主页                |
| 点击我的帖子      | 跳转我的主页，并默认打开“我的帖子”Tab |
| 点击我的收藏      | 跳转我的主页，并默认打开“我的收藏”Tab |
| 点击退出登录      | 清除登录态，跳转登录页           |
| 未登录状态点击头像区域 | 展示“登录 / 注册”按钮         |

# 3. 登录页 UI

## 3.1 页面布局

登录页采用居中卡片布局。

```text
页面背景：浅灰色

                ┌────────────────────┐
                │      社区名称       │
                │   欢迎回来          │
                │                    │
                │  账号输入框         │
                │  密码输入框         │
                │                    │
                │  [登录按钮]         │
                │                    │
                │  没有账号？去注册   │
                └────────────────────┘
```

## 3.2 组件说明

| 组件    | 类型            | 描述         |
| ----- | ------------- | ---------- |
| 社区名称  | 文本            | 页面顶部品牌名称   |
| 欢迎文案  | 文本            | 例如“欢迎回来”   |
| 账号输入框 | Input         | 输入账号       |
| 密码输入框 | PasswordInput | 输入密码       |
| 登录按钮  | Button        | 主按钮，占满卡片宽度 |
| 去注册链接 | Link          | 点击跳转注册页    |

## 3.3 交互说明

| 操作     | 效果                               |
| ------ | -------------------------------- |
| 输入账号   | 更新账号输入框内容                        |
| 输入密码   | 更新密码输入框内容，内容以密文展示                |
| 点击登录按钮 | 先进行表单校验                          |
| 账号为空   | 账号输入框下方显示错误提示“请输入账号”             |
| 密码为空   | 密码输入框下方显示错误提示“请输入密码”             |
| 登录请求中  | 登录按钮进入 loading 状态，按钮文案变为“登录中...” |
| 登录成功   | 保存 token 和用户信息，跳转首页              |
| 登录失败   | 页面顶部或按钮上方展示错误提示“账号或密码错误”         |
| 用户被封禁  | 展示错误提示“账号已被封禁，请联系管理员”            |
| 点击去注册  | 跳转注册页                            |

## 5.3 筛选 Tab

首页列表顶部有筛选 Tab：

```text
[最新] [热门]
```

### 交互说明

| 操作       | 效果                     |
| -------- | ---------------------- |
| 点击最新     | Tab 高亮“最新”，列表按发布时间倒序刷新 |
| 点击热门     | Tab 高亮“热门”，列表按热度分倒序刷新  |
| 切换 Tab 时 | 列表区域显示 loading 骨架屏     |
| 请求失败     | 显示错误状态和“重新加载”按钮        |

## 5.4 帖子卡片 UI

帖子列表中的每条帖子使用卡片展示。

```text
┌────────────────────────────────────┐
│ 头像  作者昵称    发布时间      [关注] │
│                                    │
│ 帖子标题                            │
│ 帖子正文摘要，最多展示两到三行...     │
│                                    │
│ [图片缩略图] [图片缩略图] [图片缩略图] │
│                                    │
│ ♡ 点赞数   💬 评论数   ☆ 收藏数       │
└────────────────────────────────────┘
```

### 组件说明

| 组件    | 类型         | 描述                   |
| ----- | ---------- | -------------------- |
| 作者头像  | Avatar     | 点击进入作者主页             |
| 作者昵称  | Text       | 点击进入作者主页             |
| 发布时间  | Text       | 展示相对时间               |
| 关注按钮  | Button     | 未关注显示“关注”，已关注显示“已关注” |
| 帖子标题  | Text       | 加粗显示，点击进入详情页         |
| 帖子摘要  | Text       | 最多展示 2-3 行，超出省略      |
| 图片缩略图 | Image      | 最多展示 3 张             |
| 点赞按钮  | IconButton | 图标 + 数量              |
| 评论入口  | IconButton | 图标 + 数量              |
| 收藏按钮  | IconButton | 图标 + 数量              |

### 交互说明

| 操作      | 效果                     |
| ------- | ---------------------- |
| 点击帖子标题  | 跳转帖子详情页                |
| 点击帖子摘要  | 跳转帖子详情页                |
| 点击图片缩略图 | 跳转帖子详情页，也可以后续扩展为图片预览   |
| 点击作者头像  | 跳转作者主页                 |
| 点击作者昵称  | 跳转作者主页                 |
| 点击关注    | 如果未登录，跳转登录页；如果已登录，关注作者 |
| 关注成功    | 按钮变为“已关注”，粉丝数增加        |
| 点击已关注   | 取消关注，按钮恢复“关注”          |
| 点击点赞    | 点赞成功后图标变为高亮，点赞数 +1     |
| 再次点击点赞  | 取消点赞，图标取消高亮，点赞数 -1     |
| 点击评论    | 跳转帖子详情页并定位评论区          |
| 点击收藏    | 收藏成功后图标高亮，收藏数 +1       |
| 再次点击收藏  | 取消收藏，图标取消高亮，收藏数 -1     |

### 特殊状态

| 状态    | 展示                       |
| ----- | ------------------------ |
| 列表加载中 | 展示帖子卡片骨架屏                |
| 列表为空  | 展示空状态：“还没有帖子，快来发布第一条内容吧” |
| 加载失败  | 展示错误提示和“重新加载”按钮          |
| 到底了   | 底部显示“没有更多内容了”            |

| 状态       | 表现                    |

# 27. 给智能编程助手的实现要求

请根据以上 UI 说明实现一个社区 MVP 前端项目。

## 技术要求

可以使用以下技术栈：

```text
React + TypeScript + React Router + Zustand + Axios + Ant Design
```

或者：

```text
Vue 3 + TypeScript + Vue Router + Pinia + Axios + Element Plus
```

## 实现要求

1. 页面需要完整实现前台和后台布局。
2. 所有页面需要有清晰的组件拆分。
3. 所有按钮、筛选框、Tab、弹窗、表格操作都需要实现对应交互。
4. 可以先使用 mock 数据，不强依赖真实后端。
5. 列表页需要支持 loading、空状态、错误状态、分页。
6. 表单页需要支持基础校验。
7. 点赞、收藏、关注等操作需要能在前端即时更新状态。
8. 后台表格操作需要通过弹窗确认，并刷新表格状态。
9. UI 需要保持统一风格：白色卡片、浅灰背景、圆角、轻阴影、清晰留白。
10. 页面路由需要按照本文档中的路由建议实现。
