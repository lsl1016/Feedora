# 社区 V2.1 功能完善与新增模块前端 UI 页面实现说明书

## 1. 文档目标

本说明书基于已有的增强版社区 MVP 前端项目继续补充 V2.1 功能。

新增和优化重点包括：

```text
1. 我的主页新增“我的评论”
2. 我的主页移除“我的关注”“我的圈子”
3. 新增独立“我的关注”模块
4. 新增“工作空间”模块
5. 新增笔记、知识库、AI 问答、模型配置
6. 首页增加左侧模块导航
7. 首页增加 AI 快问能力
8. 发布页支持圈子来源识别和可见范围选择
9. 圈子主页新增聊天 Tab
10. 圈子成员管理增强
11. 圈子智能摘要订阅
12. 话题页新增悬浮 AI Agent
13. 注册后弹出社区规范协议弹窗
14. 后台新增基础模型管理、Token 配置
15. 热门榜单页底部增加版权和作者信息
```

技术栈保持：

```text
React + TypeScript + React Router + Zustand + Axios + Ant Design + Vite
```

整体风格保持：

```text
浅灰背景
白色卡片
蓝色主色
圆角
轻阴影
信息密度适中
偏程序员社区 / 知识分享平台风格
```

## 2.1 社区定位

```text

```

```text

求职交流

圈子交流
AI 辅助学习
```

## 2.2 页面文案风格

页面中尽量使用偏开发者社区的文案，例如：

```text
分享你的技术经验、项目复盘或学习笔记
和同好一起讨论工程实践
把 AI 回答保存为笔记
从笔记发布成帖子

整理你的个人知识库
```

# 6. 注册后社区规范协议弹窗

## 6.1 注册流程调整

原流程：

```text
注册成功 -> 自动登录 -> 首页
```

调整为：

```text
注册成功 -> 弹出社区规范协议 -> 用户点击同意 -> 自动登录 -> 首页
```

## 6.2 协议弹窗 UI

```text
欢迎加入开发者知识社区
------------------------------------------------
本站主要面向程序员、开发者、IT 从业者和计算机学生，
用于技术知识分享、学习交流、求职经验、面试讨论、项目复盘和个人知识沉淀。

请遵守社区规范：

1. 禁止发布政治敏感内容
2. 禁止发布赌博、暴力、色情、违法违规内容
3. 禁止广告刷屏、恶意引流
4. 禁止人身攻击、辱骂、骚扰他人
5. 禁止发布游戏外挂、灰产、诈骗等内容
6. 请围绕技术学习、职业成长、知识分享进行交流

[我已同意并进入社区]
------------------------------------------------
```

## 6.3 弹窗行为

| 操作          | 效果                |
| ----------- | ----------------- |
| 注册成功        | 弹出协议弹窗            |
| 点击遮罩        | 不关闭弹窗             |
| 点击右上角关闭     | 不展示关闭按钮           |
| 点击我已同意并进入社区 | 执行登录逻辑            |
| 登录成功        | 跳转首页              |
| 登录失败        | 弹窗不关闭，提示错误        |
| 刷新页面        | 弹窗状态丢失，用户需重新注册或登录 |

## 6.4 前端状态建议

```ts
interface RegisterAgreementState {
  visible: boolean;
  account: string;
  password: string;
}
```

## 9.3 交互规则

| 场景             | 表现                       |
| -------------- | ------------------------ |
| URL 有 circleId | 请求圈子详情                   |
| 成功获取圈子详情       | 页面顶部展示“发布到：圈子名称”         |
| URL 有 circleId | 不展示“发布位置”下拉框             |
| 默认可见范围         | 圈子内可见                    |
| 选择全站可见         | 帖子同时出现在圈子和全站内容流          |
| 选择圈子内可见        | 帖子只在当前圈子可见               |
| 用户未加入圈子        | 提示“加入圈子后才能发布内容”          |
| 用户被圈子禁言        | 禁用发布按钮，提示“你已被该圈子禁言，无法发布” |
| 圈子仅管理员发帖       | 普通成员发布时提示“该圈子仅管理员可发帖”    |

## 9.4 普通发帖模式 UI
