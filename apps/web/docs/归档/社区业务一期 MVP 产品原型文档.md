# 社区业务一期 MVP 产品原型文档

## 1. 项目概述

### 1.1 项目定位

本项目是一个基础社区内容平台，支持用户发布帖子、浏览内容、评论互动、点赞收藏、关注用户，并通过通知、审核、后台管理和数据统计能力形成完整的社区业务闭环。

一期 MVP 目标不是做复杂社交平台，而是优先完成社区业务的核心链路：

```text
用户注册登录
  ↓
完善个人资料
  ↓
发布帖子
  ↓
浏览帖子列表 / 帖子详情
  ↓
评论 / 回复 / 点赞 / 收藏 / 关注
  ↓
触发通知
  ↓
内容审核与治理
  ↓
后台管理与数据统计
```

### 1.2 一期 MVP 功能范围

本期保留以下模块：

| 编号 | 模块      | 是否纳入一期 |
| -- | ------- | ------ |
| 1  | 用户体系    | 是      |
| 2  | 内容发布体系  | 是      |
| 3  | 内容浏览体系  | 是      |
| 4  | 互动体系    | 是      |
| 5  | 关系体系    | 是      |
| 7  | 通知体系    | 是      |
| 8  | 审核与治理体系 | 是      |
| 12 | 后台管理体系  | 是      |
| 13 | 数据统计体系  | 是      |

不纳入一期的模块：

| 模块        | 说明                    |
| --------- | --------------------- |
| 圈子 / 板块体系 | 一期可先用简单分类替代，不做复杂圈子治理  |
| 推荐与搜索体系   | 一期只做基础列表、热门排序、简单搜索可后置 |
| 积分与成长体系   | 后续增强活跃度时再做            |
| 活动与运营体系   | 后续配合运营需求建设            |

# 2. 用户角色

## 2.1 普通用户

普通用户是社区主要使用者。

核心能力：

| 能力      | 说明               |
| ------- | ---------------- |
| 注册登录    | 支持账号注册、登录        |
| 编辑资料    | 修改头像、昵称、简介       |
| 发布帖子    | 发布图文内容           |
| 管理自己的帖子 | 查看、编辑、删除自己的帖子    |
| 浏览帖子    | 查看全站内容、热门内容、关注内容 |
| 评论互动    | 评论、回复、点赞、收藏      |
| 关注用户    | 关注其他用户           |
| 接收通知    | 接收点赞、评论、回复、关注等通知 |
| 举报内容    | 举报帖子、评论或用户       |

## 2.2 内容作者

内容作者本质上也是普通用户，但更关注内容生产和反馈。

核心能力：

| 能力   | 说明                 |
| ---- | ------------------ |
| 发帖   | 创建内容               |
| 查看互动 | 查看帖子点赞、评论、收藏情况     |
| 删除评论 | 可删除自己帖子下的不当评论      |
| 接收通知 | 有人点赞、评论、收藏、关注时收到通知 |

## 2.3 管理员

管理员负责社区后台管理和内容治理。

核心能力：

| 能力   | 说明            |
| ---- | ------------- |
| 用户管理 | 查看用户、禁言、封禁、解封 |
| 内容管理 | 查看、审核、下架帖子    |
| 评论管理 | 查看、删除评论       |
| 举报处理 | 处理用户举报        |
| 审核配置 | 配置敏感词、审核规则    |
| 数据统计 | 查看社区核心数据指标    |
| 操作日志 | 查看后台操作记录      |

# 4. 前台页面原型

## 4.1 注册页

### 页面目标

让新用户创建账号，进入社区。

### 页面入口

| 入口      | 说明                  |
| ------- | ------------------- |
| 登录页     | 点击“注册账号”进入          |
| 未登录状态操作 | 用户点赞、评论、收藏时，引导登录或注册 |

### 页面内容

```text
注册页
------------------------------------------------
Logo / 社区名称

账号输入框
密码输入框
确认密码输入框
昵称输入框

[注册按钮]

已有账号？去登录
------------------------------------------------
```

### 字段说明

| 字段   | 类型     | 是否必填 | 校验规则           |
| ---- | ------ | ---- | -------------- |
| 账号   | string | 是    | 4-32 位，不能重复    |
| 密码   | string | 是    | 6-32 位         |
| 确认密码 | string | 是    | 必须与密码一致        |
| 昵称   | string | 是    | 2-20 位，不能包含敏感词 |

### 操作逻辑

| 操作      | 结果            |
| ------- | ------------- |
| 点击注册    | 校验表单          |
| 注册成功    | 自动登录并跳转首页     |
| 账号已存在   | 提示“账号已存在”     |
| 密码不一致   | 提示“两次输入密码不一致” |
| 昵称包含敏感词 | 提示“昵称包含不合规内容” |

## 4.3 首页帖子流

### 页面目标

展示社区内容，是用户进入社区后的核心页面。

### 页面内容

```text
首页
------------------------------------------------
顶部导航：
Logo / 首页 / 热门 / 关注 / 通知 / 我的

发布入口：
[发布帖子按钮]

帖子列表筛选：
[最新] [热门]

帖子卡片：
- 作者头像
- 作者昵称
- 发布时间
- 标题
- 内容摘要
- 图片缩略图
- 点赞数
- 评论数
- 收藏数
- 是否已关注作者
------------------------------------------------
```

### 帖子卡片字段

| 字段    | 说明              |
| ----- | --------------- |
| 作者头像  | 展示发帖人头像         |
| 作者昵称  | 展示发帖人昵称         |
| 发布时间  | 展示相对时间，例如 3 分钟前 |
| 标题    | 帖子标题            |
| 内容摘要  | 正文前 100 字       |
| 图片缩略图 | 最多展示 3 张        |
| 点赞数   | 帖子点赞数量          |
| 评论数   | 帖子评论数量          |
| 收藏数   | 帖子收藏数量          |
| 状态标识  | 已关注、已点赞、已收藏     |

### 排序规则

| Tab | 排序规则    |
| --- | ------- |
| 最新  | 按发布时间倒序 |
| 热门  | 按热度分倒序  |

一期热门分可以简单计算：

```text
热度分 = 点赞数 * 3 + 评论数 * 5 + 收藏数 * 4 + 浏览数 * 1
```

### 操作逻辑

| 操作      | 结果      |
| ------- | ------- |
| 点击帖子卡片  | 进入帖子详情页 |
| 点击点赞    | 点赞或取消点赞 |
| 点击收藏    | 收藏或取消收藏 |
| 点击作者头像  | 进入用户主页  |
| 点击关注    | 关注作者    |
| 点击发布帖子  | 进入发布页   |
| 未登录点击互动 | 跳转登录页   |

## 4.4 热门榜单页

### 页面目标

展示全站热度最高的帖子，提升内容消费效率。

### 页面内容

```text
热门榜单页
------------------------------------------------
顶部导航：
首页 / 热门 / 关注 / 通知 / 我的

1. 帖子标题

   点赞数 / 评论数 / 收藏数 / 热度分

2. 帖子标题
   作者昵称
   点赞数 / 评论数 / 收藏数 / 热度分

```

### 榜单类型

| 类型   | 时间范围            |
| ---- | --------------- |
| 今日热门 | 当天 00:00 至当前时间  |
| 本周热门 | 本周一 00:00 至当前时间 |
| 总榜   | 不限制时间           |

### 操作逻辑

| 操作     | 结果         |
| ------ | ---------- |
| 切换今日热门 | 展示今日热门帖子   |
| 切换本周热门 | 展示本周热门帖子   |
| 切换总榜   | 展示全站历史热门帖子 |
| 点击帖子   | 进入帖子详情页    |

### 页面目标

展示帖子完整内容，并承载评论、回复、点赞、收藏等互动。

### 页面内容

```text
帖子详情页
------------------------------------------------
帖子区域：
作者头像
作者昵称
关注按钮
发布时间

帖子标题
帖子正文
图片列表

[点赞] 点赞数
[收藏] 收藏数
[评论] 评论数

说点什么...

评论列表：
一级评论
  - 评论人头像
  - 评论人昵称
  - 评论内容
  - 发布时间
  - 点赞数
  - 回复按钮
  - 删除按钮

  - 回复人昵称
  - 被回复人昵称
  - 回复内容
  - 发布时间
```

### 操作逻辑

| 操作      | 结果            |
| ------- | ------------- |

| 删除自己的评论 | 评论状态变为已删除     |
| 作者删除评论  | 作者可删除自己帖子下的评论 |
| 举报帖子    | 打开举报弹窗        |
| 举报评论    | 打开举报弹窗        |
| 点击通知跳转  | 定位到指定评论位置     |

## 4.7 发布帖子页

### 页面目标

让用户创建帖子内容。

### 页面内容

```text
发布帖子页
------------------------------------------------
标题输入框

正文输入框

图片上传区域
[上传图片]

操作按钮：
[保存草稿] [发布]
------------------------------------------------
```

### 字段说明

| 字段 | 类型     | 是否必填 | 限制        |
| -- | ------ | ---- | --------- |
| 标题 | string | 是    | 5-100 字   |
| 正文 | string | 是    | 10-5000 字 |
| 图片 | array  | 否    | 最多 9 张    |

### 发帖状态

| 状态   | 说明          |
| ---- | ----------- |
| 草稿   | 用户保存但未提交    |
| 审核中  | 用户发布后等待审核   |
| 已发布  | 审核通过，对外可见   |
| 审核拒绝 | 审核未通过，仅作者可见 |
| 已删除  | 用户或管理员删除    |
| 已下架  | 管理员下架       |

### 操作逻辑

| 操作      | 结果             |
| ------- | -------------- |
| 点击保存草稿  | 保存为草稿          |
| 点击发布    | 进入审核流程         |
| 审核通过    | 状态变为已发布        |
| 审核拒绝    | 状态变为审核拒绝，并发送通知 |
| 标题为空    | 提示标题不能为空       |
| 正文为空    | 提示正文不能为空       |
| 内容命中敏感词 | 进入审核中或直接拒绝     |

## 4.8 编辑帖子页

### 页面目标

让用户修改自己发布的帖子。

### 页面入口

| 入口    | 说明           |
| ----- | ------------ |
| 我的帖子  | 点击编辑         |
| 帖子详情页 | 作者点击更多操作中的编辑 |

### 编辑规则

| 帖子状态 | 是否允许编辑       |
| ---- | ------------ |
| 草稿   | 允许           |
| 审核中  | 不允许          |
| 已发布  | 允许，编辑后重新进入审核 |
| 审核拒绝 | 允许           |
| 已删除  | 不允许          |
| 已下架  | 不允许          |

### 操作逻辑

| 操作      | 结果               |
| ------- | ---------------- |
| 修改草稿    | 保存后仍为草稿          |
| 修改已发布帖子 | 提交后状态变为审核中       |
| 审核通过    | 覆盖旧内容            |
| 审核拒绝    | 保留旧的已发布内容，新版本不生效 |

## 4.11 通知页

### 页面目标

集中展示用户收到的互动通知、审核通知和系统通知。

### 页面内容

```text
通知页
------------------------------------------------
通知类型：
[全部] [点赞] [评论] [回复] [关注] [审核] [系统]

通知列表：
- 通知图标
- 通知内容
- 时间
- 是否已读
------------------------------------------------
```

### 通知类型

| 类型   | 触发场景        |
| ---- | ----------- |
| 点赞通知 | 别人点赞我的帖子    |
| 评论通知 | 别人评论我的帖子    |
| 回复通知 | 别人回复我的评论    |
| 关注通知 | 别人关注我       |
| 审核通知 | 我的帖子审核通过或拒绝 |
| 系统通知 | 平台公告、违规处理结果 |

### 跳转规则

| 通知类型 | 点击跳转          |

# 6. 核心业务流程

## 6.1 用户注册登录流程

```text
用户进入注册页
  ↓
填写账号、密码、昵称
  ↓
前端校验
  ↓
后端校验账号是否重复
  ↓
校验昵称是否包含敏感词
  ↓
创建用户
  ↓
返回登录态
  ↓
进入首页
```

异常情况：

| 场景      | 处理           |
| ------- | ------------ |
| 账号已存在   | 提示账号已存在      |
| 密码格式不合法 | 提示密码格式错误     |
| 昵称敏感词   | 提示昵称不合规      |
| 系统异常    | 提示注册失败，请稍后再试 |

---

## 6.2 发帖审核流程

```text
用户进入发布页
  ↓
填写标题、正文、上传图片
  ↓
点击发布
  ↓
校验用户状态
  ↓
用户是否禁言？
  ├── 是：禁止发布
  └── 否：继续
  ↓
内容敏感词检测
  ↓
是否命中拦截词？
  ├── 是：提交失败
  └── 否：继续
  ↓
是否命中审核词？
  ├── 是：状态 = 审核中
  └── 否：状态 = 已发布
  ↓
发送审核结果通知
```

一期可以采用简单规则：

| 内容情况  | 状态    |
| ----- | ----- |
| 无敏感词  | 自动发布  |
| 命中审核词 | 进入审核中 |
| 命中拦截词 | 不允许提交 |

---

## 6.3 评论流程

```text
用户进入帖子详情页
  ↓
输入评论
  ↓
点击发布评论
  ↓
校验登录状态
  ↓
校验用户是否禁言
  ↓
校验帖子是否可评论
  ↓
敏感词检测
  ↓
创建评论
  ↓
帖子评论数 +1
  ↓
给帖子作者发送评论通知
```

回复评论流程：

```text
用户点击回复
  ↓
输入回复内容
  ↓
提交
  ↓
创建二级评论
  ↓
给被回复用户发送回复通知
```

---

## 6.4 点赞收藏流程

点赞帖子：

```text
用户点击点赞
  ↓
校验登录状态
  ↓
判断是否已点赞
  ├── 已点赞：取消点赞，点赞数 -1
  └── 未点赞：创建点赞记录，点赞数 +1
  ↓
如果是新增点赞，给作者发送通知
```

收藏帖子：

```text
用户点击收藏
  ↓
校验登录状态
  ↓
判断是否已收藏
  ├── 已收藏：取消收藏，收藏数 -1
  └── 未收藏：创建收藏记录，收藏数 +1
```

评论点赞：

```text
用户点击评论点赞
  ↓
校验登录状态
  ↓
判断是否已点赞
  ↓
更新评论点赞数
  ↓
如果是新增点赞，给评论作者发送通知
```

---

## 6.5 关注流程

```text
用户进入其他用户主页
  ↓
点击关注
  ↓
校验登录状态
  ↓
判断是否已经关注
  ↓
创建关注关系
  ↓
被关注人粉丝数 +1
  ↓
当前用户关注数 +1
  ↓
给被关注人发送关注通知
```

取消关注：

```text
用户点击取消关注
  ↓
删除关注关系
  ↓
被关注人粉丝数 -1
  ↓
当前用户关注数 -1
```

---

## 6.6 通知流程

```text
用户产生互动行为
  ↓
判断是否需要通知
  ↓
生成通知记录
  ↓
被通知用户进入通知页
  ↓
查看通知
  ↓
通知状态变为已读
  ↓
点击通知跳转对应业务页面
```

通知触发规则：

| 行为     | 通知接收人   |
| ------ | ------- |
| 点赞帖子   | 帖子作者    |
| 评论帖子   | 帖子作者    |
| 回复评论   | 被回复评论作者 |
| 点赞评论   | 评论作者    |
| 关注用户   | 被关注用户   |
| 审核通过   | 帖子作者    |
| 审核拒绝   | 帖子作者    |
| 举报处理完成 | 举报人，可选  |

注意：自己操作自己的内容，不需要通知自己。

# 14. 一期 MVP 不做内容

以下内容不纳入一期，避免范围失控：

| 功能     | 不做原因                          |
| ------ | ----------------------------- |
| 私信     | 增加实时通信复杂度                     |
| 圈子完整治理 | 会引入圈主、版主、圈规、成员审批等复杂能力         |
| 个性化推荐  | 需要用户画像和推荐算法支持                 |
| 积分等级   | 对核心内容闭环不是必须                   |
| 活动运营   | 属于后续运营增强                      |
| 视频内容   | 涉及上传、转码、审核和存储成本               |
| 复杂搜索   | 一期可先用数据库查询或后续接入 Elasticsearch |
| 内容付费   | 不是基础社区 MVP 必需能力               |

# 15. 一期 MVP 总结

一期 MVP 要完成的是一个最小但完整的社区闭环：

```text
用户能进来
用户能发内容
用户能看内容
用户能互动
作者能收到反馈
平台能审核治理
后台能管理
数据能被统计
```

从业务价值上看，一期重点不是“功能多”，而是证明社区产品的核心链路可用：

```text
内容生产 → 内容分发 → 用户互动 → 通知回流 → 审核治理 → 数据反馈
```

只要这条链路跑通，后续就可以继续扩展圈子、推荐、搜索、积分、活动、私信等高级功能。
