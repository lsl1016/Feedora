# 增强版社区 MVP 前端 UI 页面实现说明书

## 1. 文档目标

本文档用于指导前端页面渲染，描述增强版社区系统的前台和后台页面 UI。

重点说明：

```text
1. 页面整体布局
2. 页面包含哪些组件
3. 按钮点击后触发什么效果
4. 筛选框、Tab、下拉框如何交互
5. 弹窗、抽屉、表格、卡片如何展示
6. 空状态、加载状态、错误状态如何处理
7. 哪些组件需要联动刷新
```

本文档适用于：

```text
React + TypeScript + React Router + Zustand + Axios + Ant Design
```

也可以转换为：

```text
Vue 3 + TypeScript + Vue Router + Pinia + Axios + Element Plus
```

---

# 2. 整体 UI 风格

## 2.1 产品风格

增强版社区是一个内容社区 + 圈子 + 话题 + 搜索推荐 + 积分成长 + 活动运营平台。

整体视觉风格要求：

```text
清爽、现代、信息密度适中、偏内容阅读和社区互动。
```

## 2.2 视觉规范

| 项目   | 说明                                        |
| ---- | ----------------------------------------- |
| 主色   | 蓝色或紫蓝色，建议 `#1677ff`                       |
| 辅助色  | 绿色表示成功，橙色表示待处理，红色表示警告                     |
| 背景色  | 页面背景使用浅灰色，例如 `#f5f7fa`                    |
| 卡片色  | 内容卡片使用白色                                  |
| 圆角   | 卡片、按钮、输入框统一使用 8px - 12px 圆角               |
| 阴影   | 卡片使用轻微阴影，避免厚重                             |
| 字体   | 使用系统字体，中文优先                               |
| 页面宽度 | 前台主体最大宽度建议 1200px                         |
| 后台布局 | 左侧菜单 + 顶部栏 + 内容区                          |
| 交互反馈 | 所有按钮 hover、active、loading、disabled 状态必须明确 |

# 3. 前台整体布局

## 3.1 前台基础布局

所有前台页面共用一个顶部导航栏。

```text
┌────────────────────────────────────────────────────────────┐
│ Logo  首页  推荐  热门  圈子  话题  活动  排行榜            │
│            [搜索帖子、用户、话题、圈子...]                  │
│                    [发布]  通知  头像                       │
├────────────────────────────────────────────────────────────┤
│                                                            │
│                      页面主体内容                           │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

## 3.2 顶部导航栏组件

| 组件          | 类型              | 说明                  |
| ----------- | --------------- | ------------------- |
| Logo / 社区名称 | 文本 / 图片         | 点击跳转首页              |
| 首页          | 导航菜单            | 跳转首页内容流             |
| 推荐          | 导航菜单            | 跳转推荐内容流             |
| 热门          | 导航菜单            | 跳转热门榜单              |
| 圈子          | 导航菜单            | 跳转圈子列表              |
| 话题          | 导航菜单            | 跳转话题列表              |
| 活动          | 导航菜单            | 跳转活动中心              |
| 排行榜         | 导航菜单            | 跳转排行榜               |
| 搜索框         | Input           | 支持搜索联想、热门搜索、跳转搜索结果页 |
| 发布按钮        | Button          | 点击进入发布帖子页           |
| 通知入口        | Icon + Badge    | 有未读通知时展示红点或数字       |
| 用户头像        | Avatar Dropdown | 展示用户菜单              |

## 3.3 顶部导航交互

| 操作       | 效果                |
| -------- | ----------------- |
| 点击 Logo  | 跳转首页 `/`          |
| 点击首页     | 跳转首页内容流           |
| 点击推荐     | 首页 Tab 切换到推荐      |
| 点击热门     | 跳转热门页             |
| 点击圈子     | 跳转圈子列表页           |
| 点击话题     | 跳转话题列表页           |
| 点击活动     | 跳转活动中心页           |
| 点击排行榜    | 跳转排行榜页            |
| 点击发布     | 已登录跳转发布页，未登录跳转登录页 |
| 点击通知     | 跳转通知中心            |
| 点击头像     | 展开用户菜单            |
| 未登录时点击头像 | 显示“登录 / 注册”入口     |

```text

----------------
```

# 4. 搜索框 UI

## 4.1 搜索框基础样式

搜索框位于顶部导航中间，宽度建议 360px。

```text
[ 搜索帖子、评论、用户、话题、圈子... 🔍 ]
```

## 4.2 搜索框聚焦状态

当搜索框获得焦点，但用户未输入内容时，展示热门搜索下拉框。

```text
热门搜索
--------------------------------
1. AI 编程助手
2. Go 后端工程化
3. React 项目实战
4. 数据平台
5. 个人项目部署
```

交互说明：

| 操作      | 效果                |
| ------- | ----------------- |
| 点击搜索框   | 展示热门搜索            |
| 点击热门搜索词 | 跳转搜索结果页，并用该词作为关键词 |
| 搜索框失焦   | 延迟关闭下拉框           |
| 点击下拉框内部 | 不关闭下拉框            |

## 4.3 搜索联想状态

用户输入关键词后，展示搜索联想。

```text
搜索联想：Go
--------------------------------
帖子：Go 后端工程化实践
标签：Go语言
圈子：Go 后端开发圈
话题：#Go学习路线#
用户：Go开发小王
```

交互说明：

| 操作      | 效果              |
| ------- | --------------- |
| 输入关键词   | 300ms 防抖后请求搜索联想 |
| 点击帖子联想  | 跳转帖子详情页         |
| 点击标签联想  | 跳转标签聚合页         |
| 点击圈子联想  | 跳转圈子首页          |
| 点击话题联想  | 跳转话题详情页         |
| 点击用户联想  | 跳转用户主页          |
| 按 Enter | 跳转搜索结果页         |
| 清空输入    | 重新展示热门搜索        |
| 请求联想中   | 下拉框展示 loading   |
| 联想为空    | 展示“暂无相关结果”      |

### 筛选交互

| 操作     | 效果              |
| ------ | --------------- |

| 选择圈子   | 只展示该圈子下的帖子      |
| 选择话题   | 只展示该话题下的帖子      |
| 切换排序   | 按新排序方式刷新列表      |
| 点击重置   | 清空筛选条件，恢复默认推荐流  |
| 筛选中    | 列表展示 loading    |
| 筛选无结果  | 展示空状态“没有找到相关内容” |

```text

复制下面的链接，分享给朋友：
```

# 7. 转发弹窗 UI

## 7.1 弹窗样式

```text
转发帖子
--------------------------------
原帖：
┌────────────────────────────┐
│ 作者昵称                     │
│ 帖子标题                     │
│ 帖子摘要...                  │
└────────────────────────────┘

说点什么：
[输入框，最多 300 字]

[取消] [确认转发]
```

## 7.2 交互说明

| 操作          | 效果                    |
| ----------- | --------------------- |
| 点击转发        | 打开转发弹窗                |
| 输入转发语       | 更新转发内容                |
| 转发语超过 300 字 | 提示“转发内容不能超过 300 字”    |
| 点击取消        | 关闭弹窗，不创建转发            |
| 点击确认转发      | 创建转发内容                |
| 提交中         | 确认按钮 loading          |
| 转发成功        | Toast 提示“转发成功”，刷新当前列表 |
| 转发失败        | Toast 提示错误，弹窗不关闭      |
| 原帖已删除       | 弹窗中显示“原帖已删除，无法转发”     |
| 原帖已下架       | 弹窗中显示“原帖不可见，无法转发”     |

# 8. 发布帖子增强版 UI

## 8.1 页面布局

```text
发布帖子
------------------------------------------------
基础信息
标题输入框

正文编辑器

图片上传区

发布位置：
[选择圈子 v]

内容标签：
[搜索或选择标签]
已选标签：[Go语言 x] [项目实战 x]

关联话题：
[搜索或选择话题]
已选话题：[#AI编程助手实践 x]

发布时间：
○ 立即发布
○ 定时发布

如果选择定时发布：
[日期时间选择器]

底部操作：
[保存草稿] [预览] [发布]
------------------------------------------------
```

## 8.2 标题输入框

| 操作       | 效果                      |
| -------- | ----------------------- |
| 输入标题     | 实时更新标题                  |
| 标题为空点击发布 | 提示“请输入标题”               |
| 少于 5 字   | 提示“标题不能少于 5 个字”         |
| 超过 100 字 | 禁止继续输入或提示“标题不能超过 100 字” |

## 8.3 正文编辑器

| 操作            | 效果                |
| ------------- | ----------------- |
| 输入正文          | 实时更新正文            |
| 正文少于 10 字点击发布 | 提示“正文不能少于 10 个字”  |
| 正文超过 5000 字   | 提示“正文不能超过 5000 字” |
| 支持换行          | 展示换行内容            |
| 支持图片插入        | 可选，一期可只支持图片上传区    |

## 8.4 发布位置：圈子选择

```text
发布位置：
[不发布到圈子 v]
[Go 后端开发圈]
[React 前端圈]
[AI 工具分享圈]
```

交互说明：

| 操作        | 效果                       |
| --------- | ------------------------ |
| 点击选择圈子    | 展示我加入的圈子列表               |
| 选择圈子      | 当前帖子绑定该圈子                |
| 不选择圈子     | 帖子发布到全站                  |
| 用户未加入任何圈子 | 下拉框展示“你还没有加入圈子”          |
| 点击“去加入圈子” | 跳转圈子列表页                  |
| 用户在圈子内被禁言 | 选择后发布时提示“你已被该圈子禁言，无法发布”  |
| 圈子仅管理员可发帖 | 普通成员发布时提示“该圈子仅管理员和版主可发帖” |

## 8.5 内容标签选择

```text
内容标签：
[搜索标签]

推荐标签：
[Go语言] [React] [AI工具] [项目实战]

已选标签：
[Go语言 x] [项目实战 x]
```

交互说明：

| 操作         | 效果                    |
| ---------- | --------------------- |
| 点击标签输入框    | 展示推荐标签                |
| 输入关键词      | 搜索标签                  |
| 点击标签       | 加入已选标签                |
| 点击已选标签 x   | 移除标签                  |
| 已选标签达到 5 个 | 禁止继续添加，提示“最多选择 5 个标签” |

# 39. 通用组件交互规范

## 39.1 按钮状态

| 状态       | 表现                |
| -------- | ----------------- |
| 默认       | 正常展示              |
| hover    | 背景或边框变深           |
| active   | 有点击反馈             |
| loading  | 显示 loading，禁止重复点击 |
| disabled | 灰色不可点击            |

## 39.2 表格规范

| 行为          | 说明             |
| ----------- | -------------- |
| loading     | 表格显示 loading   |
| 空数据         | 展示“暂无数据”       |
| 分页          | 表格底部显示分页器      |
| 切换页码        | 请求对应页数据        |
| 修改 pageSize | 回到第一页并刷新       |
| 操作成功        | Toast 提示并刷新当前页 |
| 操作失败        | Toast 提示错误     |

## 39.3 弹窗规范

| 行为      | 说明           |
| ------- | ------------ |
| 点击取消    | 关闭弹窗         |
| 点击右上角关闭 | 关闭弹窗         |
| 点击遮罩    | 默认不关闭        |
| 提交中     | 确认按钮 loading |
| 提交成功    | 关闭弹窗，刷新数据    |
| 提交失败    | 弹窗不关闭，展示错误   |

## 39.4 筛选区规范

| 行为       | 说明            |
| -------- | ------------- |
| 点击查询     | 根据条件请求数据      |
| 点击重置     | 清空筛选条件        |
| 条件变化自动查询 | 前台内容流可自动查询    |
| 后台表格     | 推荐点击查询后再刷新    |
| 查询中      | 列表或表格 loading |

## 39.5 Toast 文案规范

| 场景     | 文案          |
| ------ | ----------- |
| 保存成功   | 保存成功        |
| 发布成功   | 发布成功        |
| 设置定时成功 | 已设置定时发布     |
| 转发成功   | 转发成功        |
| 复制成功   | 链接已复制       |
| 加入圈子成功 | 加入圈子成功      |
| 申请提交成功 | 申请已提交，请等待审核 |
| 操作失败   | 操作失败，请稍后再试  |
| 网络错误   | 网络异常，请稍后再试  |

# 42. 给智能编程助手的最终实现提示词

请根据本文档实现增强版社区 MVP 前端页面。

技术栈建议：

```text
React + TypeScript + React Router + Zustand + Axios + Ant Design + Vite
```

实现要求：

```text
1. 实现前台和后台两套布局。
2. 前台页面包含首页增强版、发布帖子增强版、帖子详情增强版、标签聚合、圈子、话题、搜索、任务、排行榜、活动等页面。
3. 后台页面包含标签、圈子、话题、搜索、推荐、积分、勋章、任务、活动、推荐位、公告等管理页面。
4. 所有页面需要支持 loading、empty、error 状态。
5. 所有按钮点击、Tab 切换、筛选框变化、弹窗提交都需要有明确交互。
6. 点赞、收藏、关注、分享、转发、加入圈子、签到、领取任务奖励等操作需要即时更新 UI。
7. 后台表格操作需要弹窗确认，成功后刷新表格。
8. 页面风格统一：浅灰背景、白色卡片、蓝色主色、圆角、轻阴影。
9. 可以使用 Mock 数据模拟后端接口。
10. 所有路由按照本文档路由建议实现。
```
