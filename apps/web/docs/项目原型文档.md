# 6. 首页功能说明

## 6.1 页面布局

首页采用三栏布局：

```text
左侧模块导航 + 中间内容流 + 右侧信息栏
```

左侧导航包含：

```text
首页
我的关注
工作空间
圈子
话题
活动
排行榜
官方公告
```

中间内容区包含：

```text
Banner 推荐位
AI 快问
发布入口
首页筛选栏
帖子列表
```

右侧信息栏包含：

```text
每日签到
推荐圈子
热门话题
热门搜索
热门榜单
项目信息 / 版权信息
```

---

## 6.2 首页筛选栏

筛选项：

```text
[推荐] [全部时间] [全部标签] [全部圈子] [全部话题] [重置]
```

### 用户操作说明

| 操作      | 效果                 |
| ------- | ------------------ |
| 点击推荐下拉框 | 可切换推荐、最新、关注、朋友圈、热门 |
| 点击全部时间  | 可筛选全部时间、今天、本周、本月   |
| 点击全部标签  | 按标签过滤帖子            |
| 点击全部圈子  | 按圈子过滤帖子            |
| 点击全部话题  | 按话题过滤帖子            |
| 点击重置    | 恢复默认筛选条件           |
| 筛选变化    | 帖子列表重新加载           |
| 无数据     | 展示空状态              |
| 加载失败    | 展示错误和重试按钮          |

---

## 6.3 首页 AI 快问

AI 快问用于让用户快速向 AI 提问。

示例问题：

```text
如何准备 Java 后端面试？
Go 项目怎么部署到云服务器？
React 学习路线怎么规划？
个人项目怎么写到简历里？
```

### 用户操作说明

| 操作       | 效果              |
| -------- | --------------- |
| 输入问题     | 输入框内容变化         |
| 点击发送     | 打开 AI 问答抽屉      |
| 点击快捷问题   | 自动使用该问题发起提问     |
| 未登录      | 跳转登录            |
| 未配置模型    | 提示前往模型配置        |
| AI 回答生成后 | 可编辑、保存到笔记、发布成帖子 |

# 7. 账号体系

用户输入：

```text
账号

```

点击登录后：

```text
校验账号密码
```

```text
账号为空

```

---

## 7.2 注册页

用户输入：

```text
账号
昵称
密码
确认密码
```

注册成功后不直接进入系统，而是弹出社区规范协议。

协议内容说明：

```text
本站主要面向程序员、开发者、IT 从业者和计算机学生，
用于技术知识分享、学习交流、求职经验、面试讨论、项目复盘和个人知识沉淀。

禁止发布政治、赌博、暴力、色情、违法违规、游戏外挂、灰产等内容。
```

### 用户操作说明

| 操作     | 效果        |
| ------ | --------- |
| 点击注册   | 表单校验      |
| 注册成功   | 弹出社区规范协议  |
| 点击我已同意 | 自动登录并进入首页 |
| 不点击同意  | 不进入系统     |
| 点击遮罩   | 弹窗不关闭     |

# 8. 内容发布体系

## 8.1 发布帖子

发布页支持：

```text
标题
正文
Markdown 编辑 / 预览
图片上传
标签选择
话题选择
圈子选择
定时发布
保存草稿
发布
```

---

## 8.2 从圈子进入发布页

如果用户从某个圈子点击“发布帖子”，进入：

```text
/posts/create?circleId=1
```

页面进入圈子发帖模式。

### 圈子发帖模式

页面展示：

```text
发布到：Go 后端开发圈
可见范围：圈子内可见 / 全站可见
```

不再展示“发布位置”下拉框。

### 用户操作说明

| 操作      | 效果             |
| ------- | -------------- |
| 选择圈子内可见 | 帖子只在圈子内展示      |
| 选择全站可见  | 帖子同时进入圈子和全站内容流 |
| 点击保存草稿  | 保存为草稿          |
| 点击发布    | 创建帖子           |
| 选择定时发布  | 设置未来发布时间       |
| 用户被圈子禁言 | 禁用发布按钮         |
| 未选择标签   | 提示至少选择一个标签     |

---

## 8.3 编辑帖子

用户可以编辑自己的帖子。

操作：

```text
查看帖子详情
点击编辑
修改标题、正文、图片
保存修改
```

已发布帖子修改后可重新进入审核流程。

---

## 8.4 我的帖子隐藏

用户在我的主页的“我的帖子”中可以隐藏帖子。

### 用户操作说明

| 操作     | 效果        |
| ------ | --------- |
| 点击隐藏   | 弹出确认框     |
| 确认隐藏   | 帖子状态变为已隐藏 |
| 已隐藏帖子  | 仅自己可见     |
| 点击取消隐藏 | 帖子恢复公开    |
| 点击删除   | 删除帖子      |

隐藏后的帖子不会出现在：

```text
首页
搜索
标签聚合
话题详情
圈子公开内容流
```

## 22.3 Nginx 部署


Nginx 需要支持前端路由回退：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

API 代理：

```nginx
location /api/ {
    proxy_pass http://backend:8080/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header Authorization $http_authorization;
}
```
